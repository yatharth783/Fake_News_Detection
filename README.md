## 🛠️ Technologies Used

- Python
- Machine Learning
- Scikit-learn
- NLTK
- Pandas
- Streamlit
- Joblib

## ✨ Features

- Real/Fake news prediction
- Text preprocessing
- ML-based classification
- Prediction confidence
- Interactive web interface
- Live deployment using Streamlit Cloud
